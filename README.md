# DecodeLabs | Full Stack Project 1: Responsive Layout

A professional, mobile-first responsive frontend interface built for **DecodeLabs Industrial Training Kit (Batch 2026)**. This project focuses on absolute adaptability, clean semantic architecture, and modern UI/UX design standards.

## 🚀 Project Overview

Project 1 serves as the essential entry point and prerequisite milestone for all interns. Before connecting complex backend databases, this project proves the ability to craft flexible, user-friendly frontend interfaces that render seamlessly across mobile, tablet, and desktop devices.

### Key Features
* **Semantic Integrity:** Built using proper HTML5 landmark elements (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`) to ensure accessibility for screen readers and AI agents.
* **Responsive Architecture:** Macro layouts structured via CSS Grid, micro-components via Flexbox, and fluid typography managed through `clamp()`.
* **2025 Aesthetic Design System:** Utilizes a warm and grounded palette featuring Deep Terracotta (Stability), Warm Sandstone (Trust), Pale Cream (Refinement), and Deep Navy (Focus).
* **Interactive State Management:** Lightweight, vanilla JavaScript controls for dynamic dark/light mode toggling and mobile navigation drawers.
